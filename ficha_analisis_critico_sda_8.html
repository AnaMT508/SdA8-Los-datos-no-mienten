🧠 ¿Qué significa interpretar datos con rigor?

Tener datos no es suficiente. Cualquiera puede calcular una media o trazar una recta de regresión. Lo difícil —y lo importante— es saber QUÉ se puede afirmar con esos datos y QUÉ NO. Un analista riguroso clasifica sus afirmaciones en tres categorías:

✅ LOS DATOS DICEN... Hay evidencia estadística directa y clara. Podéis afirmarlo con los números calculados.
⚠️ LOS DATOS SUGIEREN... Hay tendencia, pero hay limitaciones (muestra pequeña, período corto) que impiden certeza total.
❌ NO PODEMOS CONCLUIR QUE... El patrón existe pero no hay base para la afirmación. Se confunde correlación con causalidad.

⚖️ La Regla de Oro: Correlación ≠ Causalidad

Que dos variables estén relacionadas (r alto) NO significa que una CAUSE la otra. Hay tres explicaciones:
• A causa B: Fumar → cáncer de pulmón (causalidad real).
• B causa A: Más hospitales → más muertes (no causan muertes; ciudades enfermas hacen más hospitales).
• C causa A y B: Calor → más helados vendidos // Calor → más gente en la playa → ahogamientos (el calor explica ambas, los helados no causan ahogamientos).

Pregunta clave: "¿Existe un mecanismo real y plausible por el que X cause Y?"

📌 Ejemplo Resuelto de Referencia

Fenómeno analizado: Nivel de estudios y tasa de desempleo en municipios de Galicia.

Dato y cálculo: r = −0,71 entre % con estudios universitarios y tasa de desempleo. Por cada punto porcentual adicional de universitarios, el desempleo desciende 0,4 puntos.

✅ LOS DATOS DICEN... Existe una correlación negativa moderada-fuerte (r = −0,71) entre ambas variables.

⚠️ LOS DATOS SUGIEREN... Que los municipios con más nivel educativo tienden a tener menos desempleo.

❌ NO PODEMOS CONCLUIR QUE... Estudiar una carrera reduzca el desempleo directamente. Podría ser que municipios con más industria (variable confundidora) atraigan a ambos.

Limitación: Es un análisis transversal (un momento). No sabemos si los universitarios se quedan o emigran.
